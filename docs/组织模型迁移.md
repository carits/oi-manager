# 组织模型迁移任务

本任务用于将旧的校园档案映射为组织成员关系与组织档案。它是删除旧字段前的强制前置校验，不允许人工修改数据库或执行临时 SQL。

## 命令

```bash
pnpm --filter server migrate:organization-model:check
pnpm --filter server migrate:organization-model:apply
```

默认的 `check` 为只读演练，输出 JSON 审计报告。任一阻塞项会以非零状态退出。

`apply` 只会在没有阻塞项时使用 Prisma 业务 API 补齐以下可唯一映射的数据：

- 学校对应的组织
- 学校成员关系
- 组织内学生档案与教师档案
- 学生主教练的组织成员关系

它不会删除或修改旧表、旧字段、提交历史、比赛历史，也不会执行原生 SQL。

## 阻塞项

下列情况会阻止写入和后续 Prisma 删列迁移：

- 学生、教师或校园资源指向不存在的学校
- 同一账号在同一学校同时存在学生与教师旧档案
- 学生的主教练不属于同一学校
- 学校负责人不是本校教师
- 团队、比赛、题库、题单、管理员或负责人转移记录无法映射学校

只有报告的 `blockingIssueCount` 为 `0`，才允许进入下一步：为校园资源补 `organizationId`、切换运行时读写、最后删除旧字段和旧表。
