# UI 路由与交互矩阵

本页记录桌面端 UI 重构的验收边界。机器可读清单位于
`e2e/fixtures/ux-matrix.ts`，它从 110 条 `routePatterns` 逐条生成并校验：

- 页面所属角色和公共、平台、校园、个人模式。
- 页面类型、用户目标和主要操作。
- 搜索、筛选、分页与范围选择。
- `pending`、`ready`、`empty`、`error` 四种资源状态。
- 键盘导航、历史恢复、错误重试和筛选恢复。

路由增删时如果没有进入矩阵，测试会直接失败。`chromium-desktop` 和
`chromium-compact` 均运行全部 110 页；Firefox 继续验证登录、导航和核心流程。

## 页面族

| 页面族 | 角色/模式 | 用户目标 | 主要交互 |
|---|---|---|---|
| 登录与入口 | 公共 | 选择正确入口并登录 | 角色选择、字段校验、失败恢复 |
| 首页 | 全部角色 | 判断现在最重要的工作 | 近期任务、团队、邀请、统计入口 |
| 团队 | 工作区教师、校园学生、全角色个人工作区 | 找到自己的团队或可加入团队 | Tab、邀请、创建、分页、作用域隔离 |
| 作业与比赛 | 教师、学生 | 按时间和范围找到活动 | 状态 Tab、团队/学校范围、截止时间 |
| 题库与题单 | 平台管理员、教师、全角色个人工作区 | 在明确作用域内搜索、组织和维护题目 | 校内/平台 Tab、URL 筛选、发布、复制、归档 |
| 训练工作区 | 教师、学生 | 在一个上下文完成训练 | 吸顶 Tab、公告、题面、提交、排名 |
| 提交 | 平台管理员、教师、全角色个人工作区 | 定位提交并理解结果 | 多条件筛选、性能、代码、复制 |
| 学校与用户 | 超管、负责人、平台管理员 | 查找并维护组织和账号 | 列表、详情、编辑、状态操作 |
| AI Token | 平台管理员 | 管理 DeepSeek 总池并审计真实用量 | 汇总、正负调整、不可变流水 |
| Candidate 与评估资源 | 可提交用户、题目管理者、平台管理员 | 贡献数据、观察候选价值并限制计算/存储成本 | 阶段、预算、Corpus 摘要、Selector、Blob/GC |
| 导入 | 教师 | 按步骤导入学生或团队 | 输入、预览、冲突处理、结果 |
| 资料与安全 | 全部角色 | 维护自己的资料和凭据 | 字段校验、保存反馈、危险操作确认 |

`test-results/ui-defects.md`。报告必须包含路由、角色、视口、复现步骤和严重级别。

## 验收命令

```bash
pnpm test:ui:ux
pnpm test:ui:smoke
pnpm ui:state-check
pnpm docs:check
```

UX 全路由套件使用隔离的 E2E schema 和 `3100/3102`，不会访问开发库。

全角色个人工作区新增 19 个页面入口（16 个 `/personal/*`、3 个 `/account/*`）。
`workspace-mode.spec.ts` 对五种数据库角色逐一检查工作区切换、七个个人导航页面、岗位保持、
身份脱敏、工作接口拒绝、教师个人团队隔离以及切换失败回滚。

2026-08-01 验收快照：核心 Chromium/Firefox 冒烟组合覆盖 70/70；90 路由在
`1440×900` 与 `1280×720` 的主跑为 176/186，整改 5 条集中失败路由后聚焦复跑
10/10，组合覆盖 186/186。Critical Axe 扫描保留在核心路由，全路由继续检查异常、
失败请求、横向溢出、重复 Shell、语义标题、焦点和图标按钮标签。
