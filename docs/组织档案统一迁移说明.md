# 组织档案统一迁移

## 最终边界

全局账号只保存登录、个人资料和平台级角色。校园身份只来自组织成员关系；一个账号可以属于多个学校，在每个学校拥有独立角色。学生和教师档案只来自组织档案。学校业务资源按组织归属，历史展示使用组织档案和必要快照。

## 已移除

旧学生、教师、管理员模型、全局账号校园归属和校园资源学校归属已移除。旧教师和学生前端地址只显示已停用说明；新业务只使用组织、个人或平台规范路由。

## 验证要求

执行 Prisma 生成、服务端构建、前端类型检查、导航巡检、文档检查和真实浏览器验收。旧字段或旧 Prisma Client 调用一旦出现即视为迁移未完成。
