# 测试覆盖场景规划

> 创建时间: 2026-04-29
> 状态: 规划中

本文档规划 OI Manager V2 的全面测试覆盖场景，聚焦于权限、数据隔离、并发安全等核心问题。

## 3. 比赛赛制可见性测试场景

### 3.1 赛制类型对比

| 赛制 | 排名显示 | 题号显示 | 分数显示 | 耗时显示 |
|------|----------|----------|----------|----------|
| IOI | 实时可见 | 实时可见 | 实时可见 | 实时可见 |
| ICPC | 实时可见 | 实时可见 | AC数+罚时 | 实时可见 |
| OI | 赛后可见 | 赛后可见 | 赛后可见 | 赛后可见 |

## 6. 并发安全测试场景

### 6.1 邀请/申请并发

| ID | 场景 | 操作 | 预期结果 |
|----|------|------|----------|
| CC1 | 两个 admin 同时审批同一申请 | approve × 2 | 第一个成功，第二个返回 `REQUEST_ALREADY_PROCESSED` |
| CC2 | 学生接受邀请时邀请被取消 | accept vs cancel | 返回 `INVITATION_NOT_PENDING` |
| CC3 | 同时邀请同一学生 × 2 | invite × 2 | 第二个返回 `ALREADY_MEMBER` |

### 6.2 团队操作并发

| ID | 场景 | 操作 | 预期结果 |
|----|------|------|----------|
| CT1 | owner 转移所有权时新 owner 被移除 | transfer vs remove | 转移失败，返回 `MEMBER_NOT_ACTIVE` |
| CT2 | owner 退出团队时其他成员也在退出 | leave × 2 | 如果只剩一人则解散，否则禁止 |

## 7. 测试数据准备清单

每个测试用例需要以下测试数据：

### 7.1 基础数据

```
School × 2（本校 + 外校）
User × N（各角色）
Team × 1（本校团队）
```

### 7.2 角色组合

| 组合 | 说明 |
|------|------|
| owner + admin + member + student | 团队完整角色组合 |
| outsider | 非团队成员（同校） |
| cross-school-user | 外校用户 |

### 7.3 训练数据

| 状态 | 说明 |
|------|------|
| upcoming | 未开始训练 |
| ongoing | 进行中训练 |
| finished | 已结束训练 |

| 赛制 | 说明 |
|------|------|
| ioi | IOI 赛制（实时排名） |
| icpc | ICPC 赛制（AC 数排名） |
| oi | OI 赛制（赛后显示） |
