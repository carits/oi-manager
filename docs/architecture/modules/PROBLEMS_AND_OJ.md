# 题目、题单与外部 OJ

## 题目

题目分为 Carits 本地题目和外部 OJ 题目。统一 `Problem` 保存标题、来源、可见性、
Judge 配置和归属；题面、PDF、附件、测试数据和个人笔记使用独立模型或存储记录。

教师、平台管理员和个人模式学生可以按权限创建私有题目。编辑、删除、附件、题面和
Judge 配置都要重新验证所有权或管理员角色。

## 题单

题单由 section 和 entry 组成，支持排序、分享、学校/团队挂载和发布为作业。

- 创建者拥有管理权限。
- 分享记录区分目标和读写权限。
- 校园学生以查看分配内容为主。
- 个人模式学生可以创建和管理自己的题单。
- 发布作业时固定题目快照和目标范围，不能仅依赖前端当前列表。

## OJ 适配器

当前 `apps/server/src/oj-adapters` 有 35 个平台适配文件。适配器统一输出题目标题、
Markdown、样例、限制、来源 URL 和附件信息；外部页面变化可能导致单个平台临时失效。

抓题入口分为：

- 平台列表和单题抓取：已登录角色。
- Cookie 配置：仅超级管理员，响应脱敏。
- 批量抓题任务：超级管理员和平台管理员。
- 教师导入：通过受限的团队/题目导入流程，不获得全局任务管理权限。

## 平台绑定与账号池

用户平台绑定保存外部账号和校验状态，可同步 Codeforces/洛谷归档和提交。OJ 账号池
用于代理提交，只允许平台管理员和超级管理员管理；密码使用 `ACCOUNT_ENCRYPT_KEY`
加密存储。

## AI 翻译

题目翻译和格式整理会保护代码块、公式、URL 和样例，调用 DeepSeek 后验证占位符和
结构，再写入题面。调用量记录在 `AiUsageLog`。缺少 API Key 或校验失败时返回明确
错误，不覆盖原始内容。

外部平台研究和旧实现方案保存在[研究归档](../../archive/research/)和
[计划归档](../../archive/plans/)。
