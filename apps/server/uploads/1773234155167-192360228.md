# 问题1：排队(queue)
## 题目描述

班级里共有 $n$ 位同学，依次以 $1,2,\dots,n$ 标号。

这 $n$ 位同学想排成一行队伍，其中有些同学之间关系非常好，在队伍里需要排在相邻的位置。具体来说，有 $m$ 对这样的关系（$m$ 是一个非负整数）。当 $m\geq 1$ 时，第 $i$ 对关系（$1\leq i\leq m$）给出 $a_i,b_i$，表示排队时编号为 $a_i$ 的同学需要排在编号为 $b_i$ 的同学前面，并且两人在队伍中相邻。

求总共有多少种排队方式。由于答案可能很大，你只需要求出答案对 $10^9+7$ 取模的结果。


## 输入格式

从文件 `queue.in` 中读入数据。  

第一行，两个整数 $n,m$，分别表示同学们的数量与关系数量。

接下来 $m$ 行，每行两个整数 $a_i,b_i$，表示一对关系。

## 输出格式

输出到文件 `queue.out` 中。  

一行，一个整数，表示答案对 $10^9+7$ 取模的结果。

## 样例 1 输入

```text
4 2
1 3
2 4
```

## 样例 1 输出

```text
2
```

## 样例 2 输入

```text
3 0
```

## 样例 2 输出

```text
6
```

又是一年冬天，天寒地冻，南极大陆白雪皑皑。好渴鹅不想扑通一声掉进刺骨的冰水里，只好无所事事地呆在家里，肚子早已空空如也。在电视机上，好渴鹅发现了一种新兴钓鱼方式——冰下钓鱼：将脚底下的冰层凿穿来钓鱼。为了满足好奇心，也为了填饱肚子，好渴鹅离开了温暖的庇护所，开始尝试冰下钓鱼。

目前好渴鹅找到了 $N$ 个适合钓鱼的风水宝地，它们是相邻的。每个地点好渴鹅可以自由选择开凿深度。对于第 $i$ 个地点，每开凿 $1$ 个单位的深度需要花费 $A_i$ 的饱腹值，同时获得 $B_i$ 的饱腹值的鱼鱼来吃。存在 $A_i>B_i$ 的可能。

由于这 $N$ 个地点是相邻的，如果相邻两个地点开凿深度的绝对差超过 $1$ 个单位，那么冰层将塌方。特别地，第 $1$ 个地点和第 $N$ 个地点最多只能开凿 $1$ 个单位的深度。

现在好渴鹅想要问你在不会导致冰层塌方的情况下，他最多能够通过凿冰钓鱼的方式获得多少的饱腹值？

## 输入格式

- 第一行：一个正整数 $N$；
- 接下来 $N$ 行：第 $i$ 行两个正整数 $A_i,B_i$。

## 输出格式

一个整数，表示答案。

## 样例

### 样例输入

```

5 2
5 2
2 4
1 5
5 3
```

### 样例输出

```
8
```

## 题目描述

好渴鹅来到了渴鹅村扶贫。

村子共 $n$ 户，由 $n-1$ 条双向道路联通，根为 $1$。第 $i$ 户的贫困指数为 $a_i$（越低越贫困）。虽然贫困，但是渴鹅村村民们都是非常淳朴善良的，都想把贫困名额让给其它户。

具体来说，第 $i$ 户的心愿值为 $k_i$，表示它愿意把贫困名额让给它子树内贫困指数第 $k_i$ 小的那个（包括 $i$ 自己；保证 $k_i$ 不大于 $i$ 的子树大小）。

令 $v_i$ 为 $i$ 子树中第 $k_i$ 小的 $a_i$，即 $i$ 最终会让给的那一户的贫困指数。现在好渴鹅为了精准扶贫给了你 $m$ 次操作，每次操作都是以下两种形式中的一种：

- $\fbox{1~x~y}$：将 $x$ 户的贫困指数 $a_x$ 修改为 $y$，这将影响 $v$ 的值；
- $\fbox{2~x~y~z}$：查询在 $x$ 到 $y$ 的简单路径上，第 $z$ 小的 $v_i$。

你能帮助他完成所有的操作吗？

## 输入格式

- 第三行：$n$ 个正整数，第 $i$ 个正整数为 $k_i$；
- 接下来 $n$ 行：每行两个正整数 $U,v$ 表示一条边；
